# Release Control // Scrum Week 07

Simulador interactivo de lanzamiento (release) aplicado a gerencia de proyectos.

## Ejecutar

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

Para GitHub Pages el `vite.config.js` usa `base: './'`.

## Flujo del simulador

1. Registro del estudiante
2. Release Readiness Scanner
3. Estrategia de despliegue
4. Sala de incidentes
5. Market Radar + clasificación de feedback
6. Decisión ejecutiva final
7. Perfil, puntuación y certificado PDF
